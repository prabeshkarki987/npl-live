# NPL Live Score Live score website for the Nepal Premier League. Shows live scores, fixtures, results and a points table, in English and Nepali (नेपाली). Refreshes every 30 seconds. ## Run it on your computer 1. Install Node.js 18 or newer (https://nodejs.org). 2. Open a terminal in this folder and run: `node server.js` 3. Open http://localhost:3000 With no API key it shows clearly labelled **sample data**. ## Show real scores 1. Make a free account at https://cricketdata.org and copy your API key. 2. Copy `.env.example` to `.env` and put the key after `CRICAPI_KEY=`. 3. Restart: `node server.js` If the page shows the wrong season or no matches, find the NPL series id in the API and put it in `NPL_SERIES_ID`. The server keeps the last response for 60 seconds, so many visitors still use only about 1 API call per minute. Free plans have a daily limit, so raise `CACHE_SECONDS` if you hit it (for example 120 or 180). ## Put it online Any host that runs Node works (Render, Railway, Fly.io). Set the same values from `.env` as environment variables on the host and use `node server.js` as the start command. ## Files - `server.js` – web server and score API with caching. The `adapter` section is the only part that talks to CricketData.org, so another provider can replace it. - `public/index.html` – the whole front end. ## Known limits - The points table is worked out from finished matches (2 points per win, 1 for a tie or no result). It does not show net run rate. - Live detail depends on what your API plan provides.
