Put the team logos in this folder. The website uses them automatically.

File names must be the team's short code in small letters, with .png at the end:

  bir.png   Biratnagar Kings
  chi.png   Chitwan Rhinos
  jan.png   Janakpur Bolts
  kar.png   Karnali Yaks
  kat.png   Kathmandu Gorkhas
  lum.png   Lumbini Lions
  pok.png   Pokhara Avengers
  sud.png   Sudur Paschim Royals

A square picture, about 200 x 200 pixels, works best. A logo that is missing is
replaced by a coloured circle with the team's three letters, so you can add them one by one.
